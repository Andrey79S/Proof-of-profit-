# Token and DAO Design

The PoP protocol may utilize tokens for governance purposes.

## Token Role
- governance participation
- access control
- protocol coordination

The token does NOT:
- represent equity
- promise profit
- guarantee income

## DAO Responsibilities

The PoP DAO is responsible for governing the protocol rules, not the underlying businesses.

- define rules for accepting and structuring off-chain economic data
- choose and update data verification and validation mechanisms
- manage protocol upgrades and governance processes
- decide how verified data can be interpreted and used within the protocol

Economic decisions are always made by governance, not by the protocol itself.
