# Protocol Architecture

PoP is designed as a modular protocol consisting of three layers:

## 1. Off-chain Data Layer
This layer represents real economic activity:
- revenue
- costs
- operational metrics
- taxes and fixed expenses

Data originates from real businesses and follows a standardized format.

## 2. Verification Layer
The verification layer ensures that submitted data is:
- consistent
- auditable
- reproducible

Verification methods may include:
- documentation hashes
- oracle attestations
- DAO-based validation
- third-party verification (future)

PoP does not enforce a single verification method.

## 3. Governance Layer (DAO)
Verified data is consumed by DAO mechanisms:
- voting
- policy decisions
- treasury strategies
- protocol upgrades

The protocol itself does not dictate economic outcomes — governance does.
