Overview

Proof-of-Profit (PoP) is an early-stage protocol focused on building a verifiable financial data layer for real-world businesses.

We welcome contributors who are interested in:

- Zero-knowledge systems
- Blockchain infrastructure
- Financial data and real-world integrations

---

Ways to Contribute

You can contribute in multiple ways depending on your background:

Development

- ZK circuits (Circom, Halo2, etc.)
- Blockchain programs (Solana / Rust / Anchor)
- Backend systems for data ingestion and validation
- API integrations (POS systems, payment providers)

Research & Design

- Trust model improvements
- Data verification strategies
- ZK architecture design
- Financial modeling

Product & UX

- Dashboard concepts
- Data visualization
- Developer experience

---

Getting Started

1. Fork the repository
2. Create a new branch for your changes
3. Open an issue to discuss your idea (recommended)
4. Submit a pull request

We encourage discussion before large changes.

---

Contribution Principles

PoP is built around a few core principles:

- Clarity over complexity
- Verifiability over assumptions
- Modularity and extensibility

When contributing, aim to:

- Keep designs simple and composable
- Avoid unnecessary dependencies
- Focus on trust and data integrity

---

Current Priorities

We are currently focused on:

- Z-report data modeling and normalization
- Cross-source verification logic
- Basic proof generation (non-ZK → ZK later)
- Solana-based proof verification
